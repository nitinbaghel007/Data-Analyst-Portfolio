# 📊 Retail Store Sales Dashboard (Power BI)

## 🔎 Project Overview
This interactive Power BI dashboard analyzes retail store sales performance.
It provides insights into revenue trends, category performance, and key business KPIs.

---

## 📌 Key KPIs
- Total Revenue
- Total Orders
- Total Customers
- Average Order Value

---

## 📈 Visualizations Included
- Category-wise Revenue Analysis
- Monthly Revenue Trend
- Year-based Filtering using Slicer

---

## 🛠 Tools & Skills Used
- Power BI
- DAX Measures
- Data Modeling
- Data Cleaning using Python & SQL

---

## 💡 Business Insights
- Identified top-performing product categories
- Analyzed seasonal monthly revenue patterns
- Compared yearly performance using interactive filters
